ND

Portada principal

Noticias destacadas

Este formulario administra únicamente el carrusel Noticias destacadas de la plataforma principal. Las nuevas imágenes se guardan en Supabase Storage; las imágenes existentes alojadas en GitHub continúan siendo compatibles. No modifica el módulo completo Noti Inclusivos.

GAL

Registro visual institucional

Galería de actividades

Cada actividad puede contener entre 1 y 5 fotografías. La composición se adapta automáticamente a la cantidad de imágenes. Cada fotografía requiere su propio texto alternativo. Las nuevas imágenes se guardan en Supabase Storage; las referencias históricas alojadas en EVA/GitHub continúan siendo compatibles.
